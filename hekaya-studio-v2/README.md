# Hekaya Studio v3

Monochrome Arabic studio for automated story-to-video production.

## Server setup (Vercel)
- Project: `hekaya-studio-v3`
- Root directory: `hekaya-studio-v2`
- Production branch: `main`
- Required server-side secrets: `AI_API_KEY` (or `OPENAI_API_KEY`), `SHOTSTACK_API_KEY`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`.
- Optional image provider override: `IMAGE_API_KEY`, `IMAGE_API_BASE_URL`, `IMAGE_API_ENDPOINT`, `IMAGE_MODEL`.
- Optional text provider settings: `AI_BASE_URL`, `AI_TEXT_MODEL`.
- Optional Shotstack settings: `SHOTSTACK_ENV`, `SHOTSTACK_VIDEO_MODEL`, `SHOTSTACK_TTS_MODEL`, `SHOTSTACK_MUSIC_MODEL`.

## Workflow
1. Enter a concept in one field.
2. Story and scene production plan generated by `/api/create-story`.
3. Generate scene images via `/api/generate-image`.
4. Render final vertical/horizontal video via `/api/render-final-video` and poll `/api/final-video-status`.
5. Store projects, scenes and generation outputs in Turso and view assets in `/api/library`.

## Notes
- Do not expose API secrets in the client or GitHub.
- Provider connection checks do not incur generation charges.
- Real generation/render tests require valid provider keys and can consume credits.
- Turso must be provisioned separately and configured in Vercel environment variables.
- This studio is temporarily without an application password; protect secrets and API endpoints before public use.
