جارٍ فحص الخدمات...

أسماء المتغيرات المطلوبة في Vercel → Settings → Environment Variables
• كتابة القصص: AI_API_KEY أو OPENAI_API_KEY
• الصور: IMAGE_API_KEY (أو استخدام مفتاح القصص نفسه)
• الفيديو والصوت والموسيقى: SHOTSTACK_API_KEY
• قاعدة البيانات: TURSO_DATABASE_URL و TURSO_AUTH_TOKEN
• عناوين/نماذج اختيارية: AI_BASE_URL، AI_TEXT_MODEL، IMAGE_API_BASE_URL، IMAGE_MODEL، SHOTSTACK_ENV، SHOTSTACK_VIDEO_MODEL، SHOTSTACK_TTS_MODEL، SHOTSTACK_MUSIC_MODEL

اختبار الحالة لا ينفذ توليد صورة أو فيديو مدفوعًا. نجاح فحص المفتاح يعني أن المزود قبله، وليس ضمانًا أن كل موديل أو صلاحية توليد متاحة.
