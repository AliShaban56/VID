⚙️ اتصال محرك الذكاء الاصطناعي

الاتصال يتم من الخادم عبر API فقط. مفاتيح المزود لا تظهر في المتصفح ولا تُحفظ فيه.

أضف المتغيرات في Vercel → Settings → Environment Variables:
APP_ACCESS_PASSWORD — كلمة مرور خاصة للمنصة (مطلوبة)
AI_API_KEY — مفتاح كتابة القصص
AI_BASE_URL — عنوان API متوافق مع OpenAI (اختياري)
AI_TEXT_MODEL — موديل كتابة القصة (اختياري)
IMAGE_API_KEY — مفتاح الصور، أو استخدم AI_API_KEY
SHOTSTACK_API_KEY — مفتاح إنتاج الفيديو النهائي
SHOTSTACK_ENV — اكتب stage للتجربة أو v1 للإنتاج
SHOTSTACK_VIDEO_MODEL — اختياري، الافتراضي Seedance 2.0
SHOTSTACK_TTS_MODEL و SHOTSTACK_MUSIC_MODEL — اختياريان
IMAGE_API_KEY و IMAGE_API_BASE_URL — للتوليد المنفصل للصور المرجعية فقط

بعد إضافة المتغيرات، أعد نشر المشروع. لا تضع المفاتيح داخل الصفحة أو GitHub.
